## Decisión sobre los mockups anteriores

El sistema visual se conserva. Los mockups anteriores siguen siendo útiles como referencia, pero se generarán versiones V2 para los módulos cuya arquitectura o dominio cambió. No se sobrescriben los archivos V1: las nuevas propuestas se guardarán en carpetas V2 o con sufijo `-v2` para permitir la comparación.
